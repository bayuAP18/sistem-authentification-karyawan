8. Deployment Diagram (deployment Deployment)

3-Tier Architecture «device» Client, Server, Database Request / Response Protocols
Download Gambar PNG Buka Full Resolusi

Arsitektur fisik Deployment Diagram sistem autentikasi karyawan berbasis 3-tier node. Meliputi node fisik «device» Client (menjalankan execution environment Application Client dengan komponen Web Browser berkemampuan WebAuthn FIDO2), node «device» Server (menampung Web Server dengan komponen Node.js / Express dan Application Server dengan komponen SimpleWebAuthn serta Sequelize ORM & WS), serta node «device» Database (menjalankan DBMS dengan komponen MySQL terhubung ke basis data webauth). Komunikasi antar-node dimodelkan melalui pesan dua arah Request dan Response.

9. Component Diagram (cmp Component)

Modular Architecture «use» Dependencies Database Schema: webauth.sql
Download Gambar PNG Buka Full Resolusi

Struktur modular Component Diagram sistem presensi dan autentikasi biometrik sidik jari. Diagram ini memodelkan:

  • Komponen Perimeter (Stack Teknologi): Web Browser, Web Server, Node.js, SimpleWebAuthn, WebSocket (ws), Sequelize ORM, Express Session, FIDO2 Authenticator, dan MySQL yang terhubung melalui dependensi «use» ke proses sentral sistem.
  • Intermediary Component: Node.js / Express sebagai controller dan runtime penghubung logika server ke view.
  • Container Component View: Memuat 7 antarmuka halaman (Halaman Registrasi, Halaman Login Admin, Halaman Dashboard, Halaman Data Karyawan, Halaman Presensi, Halaman Rekap & Laporan, dan Halaman Setup Passkey (WebAuthn)).
  • Container Component Database: Berisi entitas tabel dari webauth.sql (Users, Passkeys, dan Attendances) dengan garis dependensi langsung «use» dari komponen MySQL.
